# Biz Helper CrowdMap

Краудсорсинговая карта 12 ролей помогаторов предпринимательских проектов по 9 критериям.

## Живая карта

👉 [helenforcevoice-ai.github.io/biz-helper](https://helenforcevoice-ai.github.io/biz-helper/)

## Об исследовании

Кто такой помогатор предпринимательских проектов — и чем ментор отличается от коуча, трекера, наставника и фасилитатора? Единого ответа нет. Есть холивары в чатах и подмена понятий в договорах.

Biz Helper CrowdMap — попытка построить общий язык через данные. 12 ролей оцениваются по 9 критериям на шкале от −3 до +3. Роли сгруппированы в три кластера: Источники, Катализаторы, Строители. Каждый ответ взвешивается по уровню знакомости с ролью (модель Дрейфуса).

## 12 ролей

Асессор, Бизнес-трекер, Консультант, Коуч, Ментор, Модератор, Наставник, Скрам-мастер, Супервизор, Тренер, Фасилитатор, Эксперт

## 9 критериев

| Критерий | Полюса |
|---|---|
| Объект работы | −бизнес-система / +человек |
| Направление знания | −передаёт / +извлекает |
| Инициатива и повестка | −помогатор / +подопечный |
| Дистанция от процесса | −наблюдатель / +участник |
| Горизонт работы | −стратегия / +операция |
| Формат отношений | −транзакция / +поддержка |
| Тип метода | −протокол / +адаптация |
| Ответственность | −помогатор / +подопечный |
| Длительность контакта | −разово / +систематически |

## Методология

- Взвешенное среднее: уровень 2 (понимаю суть) → вес 0.25, уровень 3 (работал с ролью) → 0.5, уровень 4 (сам в роли) → 1.0
- Данные хранятся в Google Sheets, виджет читает CSV при каждом открытии
- Автообновление каждые 5 минут
